# Central Dias

Central de gestão da Dias Centro Automotivo (central.diascentroautomotivo.com.br).
Site estático; banco e funções no Supabase (projeto dias-centro-automotivo).

Cada gravação na branch `main` publica o site automaticamente na HostGator (GitHub Actions, FTP).
Histórico e volta de versão: pelo próprio GitHub / painel de deploys.

| Arquivo | Tela |
|---|---|
| index.html | Central (menu, orçamentos, CRM, dashboards) |
| rh.html | Módulo RH (iframe) |
| gerador_orcamento_dias.html | Novo orçamento / Editar itens (iframe) |
| gerador_revisao_dias.html | Revisão Preço Fixo (iframe) |
| gerador_icf_dias.html | Gerador ICF (iframe) |
| cotacao_pecas.html | Cotação de peças |
| autorizar.html | Página pública: cliente autoriza orçamento |
| assinar-vale.html | Página pública: funcionário assina vale |
